# 算法学习仓库

这是一个个人算法与数据结构学习仓库，主要用于沉淀基础算法实现、常用数据结构练习，以及 LeetCode 刷题代码。仓库按语言和用途组织，便于对同一类题型进行复习、对比不同语言实现，并持续积累解题模板。

## 项目内容

- `rust_implement/`：Rust 版本的基础排序算法实现与性能测试入口，包含选择排序、插入排序、冒泡排序、希尔排序、归并排序和快速排序等。
- `java_implement/`：Java 数据结构练习代码，包含动态数组、链表和循环数组等基础结构。
- `js_implement/`：JavaScript 复习代码，包含常见数据结构实现和 LeetCode 题解。
- `python_implement/`：Python 题解代码，覆盖数组、字符串、滑动窗口、矩阵等常见题型。
- `leetcode/`：TypeScript 题解集合，并附带刷题方法与学习建议。

## 当前规模

- TypeScript LeetCode 题解：约 97 个
- JavaScript 练习与题解：约 124 个
- Python 题解：约 19 个
- Java 数据结构实现：约 3 个
- Rust 排序算法模块：6 类常见排序算法

## 适用场景

这个仓库适合用于：

- 复习基础数据结构与排序算法
- 按专题回顾 LeetCode 高频题
- 对比 Python、JavaScript、TypeScript、Rust、Java 的实现方式
- 整理个人算法模板和刷题记录

## Rust 代码运行

进入 Rust 子项目后可以直接运行排序算法测试：

```bash
cd rust_implement
cargo run
```

## 刷题建议

建议先掌握数组、字符串、链表、栈、队列、哈希表、二叉树等基础数据结构，再按滑动窗口、二分查找、回溯、动态规划、贪心、图论等专题刷题。遇到没有思路的题目，可以先理解高质量题解，再独立复现代码并定期回顾。
